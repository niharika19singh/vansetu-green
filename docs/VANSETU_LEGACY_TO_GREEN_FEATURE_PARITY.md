## 1. Executive Summary of Parity Audit

A rigorous, file-by-file and endpoint-by-endpoint audit was performed comparing the legacy production deployment (`van-setu-final.vercel.app`) and its local source repository against the newly unified VanSetu Green platform (`vansetu-green-staging.vercel.app`).

### Overall Parity Statistics:
- **Total Features Evaluated:** 32 distinct capabilities across 6 functional domains.
- **Complete Parity (Retained or Enhanced in Green):** 22 features (68.8%).
- **Partial Parity (Present but Missing Controls/Sub-features):** 4 features (12.5%).
- **Missing Features (Existed in Legacy, Missing in Green UI/Backend):** 6 features (18.7%).
- **Broken / Blocked Features:** 0 features.

### Core Discrepancies Requiring Integration into VanSetu Green:
1. **Map Overlays:**
   - **Road Network Layer (`roads`):** Walkable street network vector layer (`/api/roads/simple` or local GeoJSON) existed in legacy `Map.jsx`, missing in `InteractiveMap.jsx`.
   - **Roads Reference Overlay (`osmRoads`):** Esri `World_Transportation` reference tile layer (`https://server.arcgisonline.com/ArcGIS/rest/services/Reference/World_Transportation/MapServer/tile/{z}/{y}/{x}`) overlaid on rasters, missing in `InteractiveMap.jsx`.
   - **Parks & Green Spaces Layer (`osmParks`):** Curated Delhi Urban Forests & Parks GeoJSON baseline (`Central Ridge Reserve Forest`, `Sanjay Van`, `Lodhi Gardens`, etc.) with optional Overpass enrichment, missing in `InteractiveMap.jsx`.
   - **Residential Zones Layer (`osmResidential`):** Curated Delhi Residential Planning Zones GeoJSON baseline with optional Overpass enrichment, missing in `InteractiveMap.jsx`.
   - **Crisp Basemap Reference Labels:** Esri Dark Canvas reference labels (`World_Dark_Gray_Reference`) and Satellite places (`World_Boundaries_and_Places`) overlaid above rasters to prevent label obscuration.
2. **Map Canvas Controls:**
   - **Instant Location Search (`LocationSearch`):** Text search across Delhi landmarks and wards with automatic map fly-to.
   - **Quick Map Actions:** In-canvas **"🎯 Fit Corridor"** (zoom to corridor bounds) and **"🗺️ Reset View"** (reset to Delhi NCT overview) buttons.
3. **Corridor Details & Citizen Engagement:**
   - **Community Upvoting & Suggestions:** Corridor upvoting (`👍 Upvote this corridor`) and citizen suggestion submission per corridor (`suggestionsApi`).
   - **3D Corridor Physical Scene:** Procedural 3D cross-section viewer (`Corridor3DViewer`) previewing tree canopy, road widths, and shade structures.
   - **Community & Health Observation Inputs:** Citizen/vendor observational form (`SecondaryUserInput`) and health department incident logging (`HealthDataInput`).

## 3. Discrepancy Prioritization & Migration Roadmap

To achieve 100% functional parity without altering VanSetu Green's editorial design, the following targeted migrations are scheduled:

### Phase 1: Map Overlays & Spatial Canvas Parity (P0)
1. **Esri Transportation Reference Layer (`osmRoads`):**  
   Add tile overlay `https://server.arcgisonline.com/ArcGIS/rest/services/Reference/World_Transportation/MapServer/tile/{z}/{y}/{x}` in `InteractiveMap.jsx` with dedicated toggle button.
2. **Esri Crisp Reference Labels:**  
   Add `World_Dark_Gray_Reference` overlay above rasters for Dark Canvas basemap and `World_Boundaries_and_Places` for Satellite basemap in `InteractiveMap.jsx`.
3. **Parks & Green Spaces Overlay (`osmParks`):**  
   Embed curated `DELHI_PARKS_BASELINE` GeoJSON into `InteractiveMap.jsx` with green polygon styling and dedicated toggle button.
4. **Residential Planning Zones Overlay (`osmResidential`):**  
   Embed curated `DELHI_RESIDENTIAL_BASELINE` GeoJSON into `InteractiveMap.jsx` with amber polygon styling and dedicated toggle button.
5. **Walkable Road Network Overlay (`roads`):**  
   Expose `GET /api/roads/simple` in backend; render road network lines in `InteractiveMap.jsx` with dedicated toggle button.
6. **In-Map Controls (Location Search & Quick Actions):**  
   Integrate `LocationSearch` (search Delhi landmarks) and in-canvas "🎯 Fit Corridor" and "🗺️ Reset View" action buttons in `InteractiveMap.jsx` / `MapExplorerView.jsx`.

### Phase 2: Citizen Participation & Upvoting Parity (P1)
1. **Corridor Upvoting:**  
   Add backend endpoint `POST /api/corridors/{id}/upvote` and `GET /api/corridors/{id}/upvotes` in `corridors.py`; add upvote button in `CorridorAnalyticalDetail.jsx`.
2. **Community Suggestions:**  
   Add backend endpoints `GET /api/corridors/{id}/suggestions` and `POST /api/corridors/{id}/suggestions` in `corridors.py`; add suggestions tab/card in `CorridorAnalyticalDetail.jsx`.
3. **3D Corridor Physical Scene:**  
   Port `Corridor3DViewer.jsx` into `vansetu-green/frontend/src/components/` and provide a 3D cross-section viewer toggle in `CorridorAnalyticalDetail.jsx`.
4. **Community Observation Forms:**  
   Provide quick modal triggers for `SecondaryUserInput` (vendor observations) and `HealthDataInput` (health incident reports) in the public discovery interface.
